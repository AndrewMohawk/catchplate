About this demo workspace
This is a persistent, synthetic development sandbox. The Rust proxy, HTTPS interception and local audit storage are real; the upstream service and credentials are test-only. No real provider is connected.
It does not establish production readiness, enclave or hardware verification, native authority, or atomic release authorization. Streaming request transformations are unsupported and refused. Rejected test requests are expected in a successful demo.
The full product workflow is to connect a provider, set allowed actions, give an application scoped access, then review its activity. The sandbox does not yet enable that production onboarding flow.
