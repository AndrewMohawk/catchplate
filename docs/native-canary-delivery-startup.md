# Explicit native durable-canary startup

Native startup v19 is a closed, explicitly selected composition of v18 and
required `measuredCanaryDelivery`. It retains the genuine measured succession
and historical-key broker/v2 owners, encrypted service-token admission, original
native lifetime, guest cohort, gate cgroup and all other v18 components. It does
not select active reconnect, replace a browser purpose, create a second helper,
or turn canary observations into OAuth or release authority.

The image selector `--measured-canary-delivery-v19` maps only to the fixed gate
selector `--native-measured-canary-delivery-startup-v19`. The decoder accepts
only `catchplate.nativeStartupConfiguration/v19` for that mode, with exactly
the v18 fields plus required nonnull `measuredCanaryDelivery` (23 total).
No version is inferred from an incoming request or an optional field. V1–v18
retain their wire grammars and internal canary input `None`; old selectors refuse
v19. The original 16 MiB complete configuration bound remains unchanged.

The nested object uses the actual
`native_canary_delivery_v1::Configuration` closed ten-field contract, including
the independent root, exact signed authority configuration original, explicit
canary assignments and observation-only `recoveryTargets`. Its real `validate`
method independently admits those originals. V19 also requires its deployment
and instance to match the selected succession/currentness scope, without
substituting either purpose's trust roots or permission for the other.

The unchanged configuration value is passed to the actual
`GateStateInputs.measured_canary_delivery` member. The separate durable-canary
implementation retains and initializes its real owner through native bootstrap;
this decoder does not manufacture an initialized owner, a delivery receipt,
synthetic evidence, a holder acknowledgement or a successful intake. The actual
sender still consumes its separately signed assignment, protected durable
prepare/claim state, genuine evidence and original operation deadline. A
recovery target selects observation only: no replayed claim/contact, renewed
window or automatic continuation follows from missing acknowledgement.

The paired [v19 schema](../schemas/native-startup-configuration.v19.schema.json)
references the unchanged v18 properties and the actual durable-canary
configuration schema. The new decoder and schema are in the Make source
inventory. No native `run` signature, signer, sender implementation, policy
profile, cohort literal or default startup is replaced by this composition.

This is source wiring, not runtime acceptance. The actual durable-canary
owner/bootstrap implementation and its schema are integrated with this decoder;
independently provisioned signed configuration and assignments remain required.
No build, parser, test, browser, kernel/network execution, provider or
cloud action was performed. Actual cold admission, stale/foreign purpose
refusals, recovery without replay, original lifetime and end-to-end delivery
remain unverified.
