Proxy setup

Connect your existing HTTP client through Serverware using the proxy address, public CA and an application token. The console URL is not the forward proxy.

Use your existing client's proxy settings

Keep your client's API URL, method and request data. Configure its HTTPS proxy endpoint below, send the application token as proxy authentication, and trust the downloaded CA for the destination inside the tunnel. Your client must support these proxy and TLS settings.

Every request must still match an active access rule. Follow that rule's credential-input choice: send no provider credential header for automatic insertion, or exactly the configured dummy value for replacement.
